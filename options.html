Options · 30 power features

Feature toggles

Toggle any of the 30 features on or off. Changes apply immediately on the next fmhy.net page load.

Cross-device sync

Sync your bookmarks, notes, and ratings across browsers via GitHub Gist or WebDAV. Your data lives only in your private Gist / WebDAV server.

Create one at github.com/settings/tokens with the gist scope.

Last sync: never

Highlight rules

Define patterns to highlight resource links on fmhy.net. Patterns are case-insensitive regex.

Watched categories

Get notified when new resources are added to categories you care about.

Backup & restore

Export all your data (bookmarks, notes, ratings, settings) to a JSON file, or import from a previous backup.

Danger zone

Wipe all FMHY Supercharged data from this browser. This cannot be undone.

About FMHY Supercharged

A Manifest V3 browser extension that adds 30 power features to fmhy.net.

Features (30)

    Keyboard shortcuts

    Ctrl+Shift+KOpen command palette
    Ctrl+Shift+BBookmark current page
    Ctrl+Shift+SpaceOpen category radial menu
    j / kMove between resource links
    EnterOpen active link
    bBookmark active link
    nAdd note to active link
    /Focus search
    ?Show keyboard help
